# A6 成交量与价格

状态：未实现。

教材要求：K 线加成交量柱，展示放量上涨、缩量上涨、放量下跌、缩量下跌，并注明计量单位。标明「教学模拟」。

教材例子：过去 20 根平均成交 1000 BTC，本根 1800 BTC，可视为相对放量。四类组合的具体 OHLC 和成交量待教材补全。

## 数据

- 基准：20 根平均 1000 BTC。
- 相对放量示例：1800 BTC。
- 四类 K 线各自的开高低收和成交量待教材补全。
- 单位必须写明是 BTC 成交量，不和 USDT 成交额混用。

## 交互

- 切换四类，或四栏并排。
- 点选后显示该根 OHLC、成交量和它相对 1000 BTC 的倍数。不依赖悬停。

## 标签

| 键 | 中文 | English |
| --- | --- | --- |
| 标记 | 教学模拟 | Teaching simulation |
| 类型 | 放量上涨 / 缩量上涨 / 放量下跌 / 缩量下跌 | High-volume rise / Quiet rise / High-volume drop / Quiet drop |
| 单位 | BTC | BTC |

## 验收

- 1800 相对 1000 显示为 1.8 倍。
- 图上写明缩量或放量都不能单独预测下一根涨跌。
