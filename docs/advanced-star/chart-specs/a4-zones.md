# A4 支撑与压力

状态：未实现。

教材要求：半透明支撑带和压力带，分别演示反弹、假突破、跌破。标明「教学模拟」。

教材例子：98–102 多次止跌，可暂当候选支撑；之后跌到 90，表示这次没有守住。压力带的价位和三套走势的完整路径待教材补全。

## 数据

- 支撑带：98–102。失效后的低点：90。
- 压力带与三条路径的逐点价格待教材补全。

## 交互

- 切换反弹、假突破、跌破。
- 带是区域，不是一条绝对价。点选后显示该区域和结果。不依赖悬停。
