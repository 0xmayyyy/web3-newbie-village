# A5 突破、假突破与回踩

状态：未实现。

教材要求：三个可揭晓后续走势的情景：震荡、假突破、突破回踩。标明「教学模拟」。

教材例子：区间 95–105。价格刺到 107 又收回 103，是假突破。另一段收在 108，回踩 105 后继续上行，是突破回踩。震荡情景的具体路径待教材补全。

## 数据

- 区间：95–105。
- 假突破：高点 107，收回 103。
- 突破回踩：收在 108，回踩 105，然后继续上行。上行的后续价位待教材补全。
- 震荡路径待教材补全。

## 交互

- 先只显示区间和第一笔，再由用户揭晓后续。
- 三个情景可切换。不依赖悬停。

- 假突破回到区间内。
- 突破回踩先站到区间外，再接近边界。
- 揭晓前不把结果画出来。
