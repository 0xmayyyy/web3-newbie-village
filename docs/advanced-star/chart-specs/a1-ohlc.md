# A1 一根 K 线的 OHLC

状态：已在 PR #24 实现。

教材要求：两根可切换红绿 K 线，点选显示 OHLC；同一 OHLC 展示两种不同盘中路径。标明「教学模拟」。

## 数据

- 收盘高于开盘：开 100、高 110、低 95、收 106。
- 「开收对调」使用同一高低：开 106、高 110、低 95、收 100。这不是另一段行情。
- 路径一：100 → 110 → 95 → 106。
- 路径二：100 → 95 → 110 → 106。
- K 线由路径算出：开盘是第一个价，收盘是最后一个价，最高是最大值，最低是最小值。两条路径都得到开 100、高 110、低 95、收 106。

## 交互

- 点「看这根 K 线」或「同一 OHLC 的两条路径」。不依赖悬停。
- 点选后，读数区写出开、高、低、收，以及实体、上影、下影区间。
- 可改四个价格。最高低于开盘或收盘、或最低高于开盘或收盘时，不更新图并显示错误。
- 图下注明：收盘高于开盘常画绿色，低于开盘常画红色，但平台配色可能相反。

## 验收

- 教材例子的实体是 100–106，上影 106–110，下影 95–100。
- 两条路径算出的 OHLC 相同，图上的顺序不同。
- 手机上用点击完成，不需要悬停。
