# A3 高点与低点

状态：未实现。

教材要求：HH/HL 上升、LH/LL 下降、横盘三栏。点选摆动点，立即反馈对错。标明「教学模拟」。

教材例子：高点 100 → 110 → 120，低点 90 → 98 → 105。跌破 105 只提示结构可能变化，不保证反转。横盘栏的具体价位待教材补全。

## 数据

- 上升栏使用上面的高点与低点。
- 下降栏与横盘栏的确定价位待教材补全。

## 交互

- 三栏并排或分段切换。
- 点选一个摆动点后立即显示对或错。不依赖悬停。

## 标签

| 键 | 中文 | English |
| --- | --- | --- |
| 标记 | 教学模拟 | Teaching simulation |
| 结构 | 上升 / 下降 / 横盘 | Rising / Falling / Sideways |
| 点 | HH、HL、LH、LL | HH, HL, LH, LL |

## 验收

- 上升栏的高点和低点都逐次抬高。
- 点错时说明它为什么不是该结构的摆动点。
