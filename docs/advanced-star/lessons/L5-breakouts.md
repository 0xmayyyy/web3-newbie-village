# 【教材已备·待开发】L5｜突破、假突破、回踩与震荡｜三条分支互动教材

> 教材与开发规格初稿；对应 Issue #34。待课程内容与英文文案最终审阅。

**一句话讲懂**：越过边界不等于稳稳突破；区分影线越界、收盘越界、回踩和重新跌回。
**教学规则**：候选震荡区100–110，上边界观察带109–111；本课明确用**4h收盘价>111**作为“收盘突破”条件（仅本课教学标准，不是交易信号）。
**基础8根4h OHLC**：1(103,106,101,105);2(105,109,104,108);3(108,110,105,106);4(106,107,100,102);5(102,105,99,104);6(104,109,103,108);7(108,110,106,107);8(107,109,102,105)。
**三条互斥后续情景**：
- A：9(105,113,104,108);10(108,109,103,104)。影线越界但第9根收108，不符合收盘>111。
- B：9(105,114,104,112);10(112,113,109,110);11(110,116,109,115)。第9根收盘越界，第10根回踩附近，第11根上行；不是保证模式。
- C：9(105,114,104,112);10(112,113,105,107);11(107,109,101,103)。第9根收盘越界，第10根收盘重回区间，之后才可描述未维持突破。
**互动**：先显示8根共同历史，逐根揭晓，学员判断“影线/收盘/未越界”；选择A/B/C分支后显示不同后续，不得在第9根提前标“假突破”；三分支共用固定价格轴。主图有价格/时间轴、红绿实体和影线。
**练习**：H113 C108门槛111，是否满足收盘突破？B不满足。
**三题**：①H113 C108门槛111，A满足/B不满足/C一定假突破，答案B；②先收112再收107，A必涨/B回到区间/C不知收盘，答案B；③回踩A必成功/B必反转/C返回测试边界但结果不定，答案C。
**误区**：影线越界≠收盘确认；收盘突破仍可失败；回踩不是必然发生；不能提前知道假突破。
**美术**：Q版女生面对三扇剧情门，主图一键切换三种真实K线结局；重点放大最高113与收盘108。
**实验室**：BTCUSDT 4h，区分最近一次越界属于影线还是收盘。
**验收**：教学模拟/非建议、TTS、中英、移动端、答题反馈、独立PR，不动L1/L2。

**开发顺序**：按L3→L4→L5→L6依次实现；先完成本节并提交PR，再继续下一节。站长审核前不得合并。
