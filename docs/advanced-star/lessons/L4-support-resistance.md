# 【教材已备·待开发】L4｜支撑与压力｜教材与可拖拽区域交接

> 教材与开发规格初稿；对应 Issue #33。待课程内容与英文文案最终审阅。

**一句话讲懂**：支撑压力是过去曾有交易反应的**价格区域**，不是碰到就必反弹的神奇线。
**正文**：支撑区为过去价格下探时曾出现反应的区间，压力区为上行时曾出现反应的区间；区域宽度由影线、波动和多次反应综合观察。价格可以穿越区域，角色转换不是必然。
**模拟4h OHLC（O,H,L,C）**：1(103,106,101,105);2(105,107,102,103);3(103,104,99,101);4(101,106,100,105);5(105,110,104,109);6(109,111,106,107);7(107,108,102,103);8(103,105,98,101);9(101,107,100,106);10(106,110,105,109);11(109,112,107,111);12(111,113,104,105)。
候选支撑98–102；候选压力109–112；只是教学示例，不是必然有效区间。
**互动**：用户拖动两条边界圈支撑/压力带，点击历史K线查看反应，按“显示参考”出现半透明示范带；合理宽度范围接受，不做像素级判错；播放后续蜡烛观察穿越。
**练习**：98–102多次下探后回升→A绝对底部/B候选支撑区/C下一根必涨；答案B。
**三题**：①区域还是永不失效精确线？B区域；②第三次触支撑必反弹/必跌破/仍需观察？C；③穿过压力后立刻宣布永久支撑/观察后续/删历史？B。错误反馈必须有原因。
**误区**：多次测试≠永不跌破；压力突破≠必然变支撑。
**美术**：墨镜Q版女生拿半透明荧光笔在真实K线图画带状区域；主图轴、影线和价格刻度明确；别画单根水平神线。
**实验室**：BTCUSDT 4h圈两块区域，切1D比较。
**验收**：教学模拟、中文优先英文待审、TTS、手机拖拽/键盘、独立PR；不得改L1/L2或V23核心。

**开发顺序**：按L3→L4→L5→L6依次实现；先完成本节并提交PR，再继续下一节。站长审核前不得合并。
