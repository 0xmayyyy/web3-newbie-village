# 给编程布｜进阶知识星第一章实施说明

目前正在整合 V23 星际行情实验室。课程开发请另开分支，**不要修改** V23 多窗格引擎、SMC算法、指标计算或行情请求逻辑。

## 任务
1. 将六节 Markdown 教材接入网站课程路由、目录和进度系统，遵循现有项目架构。
2. 按教材 A1–A6 制作六套**可交互且数据精确**的 SVG/Canvas 教学图：OHLC、时间聚合、HH/HL、支撑压力区、突破回踩、成交量。每张图标明“教学模拟”。
3. 课程配上一课/下一课、答题即时反馈、学习进度和返回目录；优先复用现有组件与存储。
4. 每课增加「去星际行情实验室练习」入口。设计可维护的 symbol、interval、studies 传参协议；只有实验室真正支持读取时才启用自动预选，不要假装已生效。
5. 接入网站现有中英文系统；所有UI与图中标签双语，正文英文须审核后发布。
6. 适配 375、390、430、768px及桌面；实测 iOS Safari 和 Android Chrome 的触屏、滚动、测验、图表。
7. 保留无障碍文字、键盘操作和减少动画偏好。

## 验收
- 六课内容与测验正确；示意图OHLC逻辑无误，时间聚合正确。
- 手机可读、可操作，交互图不依赖鼠标悬停。
- 课程与行情实验室跳转参数实际有效或明确标注暂不支持。
- V23 原有功能不倒退。

## 分工
我负责：教材正文、例子、错误观念、小测与答案、A1–A6图解说明。
编程布负责：交互图绘制、组件、路由、双语接入、进度记录、移动端适配、联动与测试。
