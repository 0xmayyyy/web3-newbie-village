# 【教材已备·待开发】L6｜成交量与价格｜双窗格互动教材

> 教材与开发规格初稿；对应 Issue #35。待课程内容与英文文案最终审阅。

**一句话讲懂**：价格反映这段时间的结果向哪边移动；成交量表示成交数量，不能单靠它预测下一根。
**术语**：成交量是指定市场、时段的成交标的数量；成交额是逐笔价格×数量求和；持仓量是未平仓合约规模，非成交量。现货/永续口径不可混淆。每笔成交有买卖双方，成交量柱不是“净买入量”。
**模拟现货4h数据**，格式(O,H,L,C,成交量BTC)：1(100,103,99,102,80);2(102,106,101,105,120);3(105,107,103,104,95);4(104,110,103,109,180);5(109,111,107,108,130);6(108,112,107,111,75);7(111,112,106,107,210);8(107,109,104,105,160)。
**主图**：上下同步时间轴；上方真实OHLC蜡烛与价格轴，下方成交量柱与BTC单位轴；点击2/6/7根，上下同步高亮，比较开收和前一根量。
**四种观察**：涨+量增、涨+量减、跌+量增、跌+量减；本课量增减统一定义为“与上一根K线比较”。不能把缩量上涨写成“必跌”。
**练习**：第6根O108 C111 V75，前根V130 → A缩量上涨（对）/B放量上涨/C必跌。
**三题**：①第7根O111 C107 V210，前根V75 → B放量下跌；②成交量柱A只有买入/B买减卖/C指定时段成交数量 → C；③缩量上涨A下一根必跌/B量低于比较基准但后续不定/C必被操纵 → B。
**误区**：量大不必涨；量小不必跌；现货量≠合约量；收盘价×成交量非精确成交额。没有逐笔成交数据时，不可伪造精确成交额。
**美术**：两家奶茶店“同样价格变化、不同销量”的情境小图；Q版墨镜女生；主图上下双窗格、四象限可点击，切忌画一排等高矩形。
**实验室**：BTCUSDT 4h挑一涨一跌K线比较成交量，先核对数据源口径。
**验收**：教学模拟、TTS、中英、手机、答案反馈、独立PR、不修改L1/L2。

**开发顺序**：按L3→L4→L5→L6依次实现；先完成本节并提交PR，再继续下一节。站长审核前不得合并。
