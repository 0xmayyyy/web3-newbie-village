# 第八章｜交易心理与复盘（三节）中文实施稿

## L1 FOMO与冲动交易
正文：“最容易追进去的那根大阳线，往往也是最难冷静思考的时候。”屏1模拟一段上涨K线与群聊热度（明确虚构），用户选“立刻追/先看计划/放弃”；屏2展示两种可能后续（继续涨或快速回落），不暗示哪个必然；屏3用户填写入场理由、止损、仓位，未填风险项时显示提醒而不是替用户下单；屏4总结FOMO与确认偏误。测验①怕错过是 A FOMO/B套利/C对冲，A；②上涨快就必须追？A是/B否/C只BTC，B；③先写计划有帮助？A有/B没有/C保证盈利，A。

## L2 亏损厌恶、报复性交易与过度自信
正文：“亏了一笔最危险的念头，可能是‘下一笔一定要赚回来’。”屏1给亏损后情景卡，选择加倍仓位/按计划休息/复盘；屏2权益曲线对比固定风险1%与亏损后风险翻倍的模拟路径；屏3标注这些是风险演示不是心理诊断；屏4给出暂停条件、最大单日风险预算、复盘模板。测验①亏后翻倍一定回本 A是/B否/C仅合约，B；②连续亏损后可以先暂停？A可以/B不行/C违规，A；③情绪强烈时是否适合自动加仓？A适合/B不应仅凭情绪/C必赚，B。

## L3 复盘闭环与长期习惯
正文：“复盘不是给过去找借口，而是给下一次少犯同样的错。”屏1展示10笔虚构交易日志，包含计划、执行、费用、结果、情绪备注；屏2学员筛选“计划正确但亏损/违反计划但盈利”等四象限，强调结果好不等于过程好；屏3生成每周检查表：是否遵守仓位、是否追单、是否记录失效条件、策略是否需要足够样本；屏4导出本地CSV/中文复盘卡，未经允许不上传。测验①盈利单一定执行正确 A是/B否/C看涨幅，B；②复盘应看 A过程与结果/B只盈亏/C只胜率，A；③小样本胜率保证未来 A是/B否/C10笔足够，B。

**图表要求**：两种权益路径必须由相同明确收益序列与不同仓位规则计算，禁止画成“自律者永远赚”的虚假因果图；所有例子为模拟；本地存储与删除可控；中文审核前禁止翻译。
