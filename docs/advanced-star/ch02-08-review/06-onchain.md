# 第六章｜链上数据与资金流向（四节）中文实施稿

关联Issue #51。

**L1 区块浏览器**｜正文：“区块浏览器像查快递，但查到‘已送达’不等于你知道收件人是谁。”屏1展示教学模拟交易哈希、链名、区块高度、发送/接收地址、Token合约、100 USDT、Gas、状态；屏2学员点击查网络/合约/收款地址；屏3给同名假USDT合约识别题；屏4强调交易成功不等于交易所到账；测验①链名要核对 A是/B否/C只有跨链，A；②成功=对方身份确定 A是/B否/C永远交易所，B；③同名代币必相同 A是/B否/C只有USDT，B。

**L2 交易所净流入**｜正文：“钱包转进交易所，不等于已经卖掉。”屏1展示外部→交易所1000、交易所→外部700、交易所内部划转500；屏2拖动三条转账箭头到流入/流出/内部；屏3排除内部后净流入+300；屏4增加未知地址标签，提示统计不完整；测验①内部划转算外部净流入 A算/B不算/C看币价，B；②+300等于卖出300 A是/B否/C必然，B；③标签会有漏标 A会/B不会/C仅小链，A。

**L3 稳定币Mint/Burn**｜正文：“看到TRON增发USDT，先别急着喊‘钱要冲进BTC了’。”屏1单链供应图；屏2模拟A链mint 100m、B链burn 100m，切换单链/跨链汇总；屏3区分发行人库存、流通供应、跨链迁移的可能解释；屏4强调不能仅凭同额推断迁移；测验①单链mint=全网必增 A是/B否/C仅USDT，B；②mint=立刻买BTC A是/B否/C一定买ETH，B；③跨链需核对多链 A是/B否/C不必，A。

**L4 TVL与巨鲸**｜正文：“TVL涨了，不一定是有人往里充钱，也可能只是币涨价。”屏1协议持100 ETH、单价2000 USDT，TVL=200000；屏2价格涨到2500、数量不变，TVL=250000，涨25%，**无净流入**；屏3用户调整币价与数量，拆分估值变化和净数量变化；屏4地址数≠人数、巨鲸转账≠卖出；测验①TVL涨25%必有净存入 A是/B否/C只有DeFi，B；②活跃地址=人数 A是/B否/C必一人一地址，B；③巨鲸转账必砸盘 A是/B否/C只交易所，B。

**验收**：每条真实链上数据需链、合约、区块高度/时间、来源、标签口径；模拟数据必须明显标识；箭头与数额守恒；USDT发行与链上转账不能直接推断市场交易；中文先审。
