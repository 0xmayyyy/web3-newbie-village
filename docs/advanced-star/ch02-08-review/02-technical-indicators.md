# 第二章｜技术指标与信号（七节）中文逐屏补充

关联PR #39及Issue #46。中文版教材以PR #39为初稿，以下补充实施细节，中文内容尚待用户审核。

**L1 EMA**｜开场：“均线为什么总追着价格跑？”屏1让用户猜大跌后EMA是否立即等于收盘价；屏2叠加K线与EMA3、EMA5；屏3点击第5根，展示Close=98、前EMA3=101.25、α=0.5、新EMA=99.625；屏4切震荡序列看假交叉；屏5测验。固定收盘[100,102,104,100,98]，EMA3=[100,101,102.5,101.25,99.625]。测试首值=首收盘，切参数必须重算，图线不得超出当前回放时间。题：①EMA新值一定等于新收盘？A是/B否/C仅下跌时；B。②短EMA通常？A更快/B永远更准/C不动；A。③横盘交叉？A必赚/B可能噪声/C必跌；B。错误反馈分别解释加权、灵敏度不等于准确、横盘来回穿越。

**L2 MACD**｜开场：“柱子缩短，币就要跌了吗？”屏1猜；屏2切换EMA12/26、DIF、DEA9、柱；屏3逐根展示DIF−DEA；屏4看价格仍涨但柱缩短的**由完整价格序列计算**反例；屏5测验。默认柱值DIF−DEA，注明部分平台画2倍；预热期无有效数据要标“计算中”，不可补假值。测验①DIF2.4 DEA1.9柱值 A0.5/B4.3/C−0.5，A；②柱缩短价格必跌 A是/B否/C必横盘，B；③柱倍数不同可能因 A定义不同/B币种不同必然/C软件错误，A。

**L3 RSI**｜开场：“RSI到80为什么还能涨？”屏1猜70是否卖出命令；屏2 14周期Wilder RSI，主图价格副图RSI并标70/30/50；屏3查看某根涨跌幅、平滑平均涨/跌、RSI；屏4持续上涨与横盘反例；屏5测验。仅14个价格变化后产生首个有效RSI；平均跌=0且涨>0则100，两者=0本课约定50。测验①RSI75意味着 A75%涨/B上涨力度相对强/C下一根必跌，B；②强趋势可持续超买 A可以/B不可以/C最多两根，A；③RSI是 A概率/B相对涨跌力度/C交易量，B。

**L4 布林带**｜开场：“缩口以后一定暴涨？”屏1选择上涨/下跌/无法确定；屏2显示20周期SMA±2σ；屏3调整周期N∈[5,50]、倍数k∈[1,3]、步进合理离散值；屏4展示同一缩口后两种不同后续走势；屏5测验。σ采用总体标准差除N；验证[98,100,102]、N3、k2：中轨100，上103.266，下96.734。测验①中轨常用 A均线/B成交量/C持仓量，A；②缩口方向 A必涨/B必跌/C不确定，C；③带宽大 A价格更分散/B必跌/C成交量必高，A。

**L5 背离**｜开场：“价格创新高，指标却没创新高，能直接做空吗？”屏1猜；屏2价格与RSI双窗格，用户只能选已确认的价格峰谷及时间对应的指标峰谷；屏3连线并显示价格HH、指标LH等；屏4播放背离后仍上涨反例；屏5测验。示意峰谷价格105→112、RSI78→69仅是**关系例子**，实现必须用一套完整OHLC计算出真实RSI并验证，不能把任意四个数硬贴到曲线上。测验①价格HH+RSI LH A看跌背离/B必涨/C无关系，A；②背离 A保证反转/B提示风险/C保证横盘，B；③峰谷 A可事后乱挑/B需按确认规则对应/C任意选，B。

**L6 斐波那契**｜开场：“0.618是不是神奇买点？”屏1猜；屏2两锚点，100→140，逐级显示回撤130.56、124.72、120、115.28、108.56；屏3用户拖动锚点，价位实时重算；屏4展示跌破0.618反例；屏5测验。上涨回撤P=H−(H−L)r，下跌反弹P=L+(H−L)r；0.5不是严格斐波那契比例。测验①0.618对应 A115.28/B124.72/C140，A；②换锚点价位 A变化/B不变/C必上涨，A；③0.618 A必反弹/B只是参考/C保证不破，B。

**L7 SMC**｜开场：“图上一个OB，就能证明机构买入吗？”屏1猜；屏2依次打开已确认结构点、BOS、CHoCH、FVG、OB候选；屏3点击标签展示本课具体判定条件；屏4逐根揭示假信号；屏5测验。FVG例A高103、C低106→上涨FVG区间103–106；不得声称该区间绝无成交。BOS/CHoCH不同流派口径不统一；不得改V23现有算法。测验①FVG代表绝对无成交 A是/B否/C必然，B；②OB证明机构持仓 A是/B不能/C必然，B；③结构标签能保证走势 A能/B不能/C仅BTC能，B。

**统一验收**：切换参数重算、公式单测、时间轴同步、手机双窗格可操作、无未来函数、错误反馈解释原因、图表无随意手绘。英文暂不开发。
