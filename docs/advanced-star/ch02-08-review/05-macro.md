# 第五章｜宏观经济与市场周期（五节）中文实施稿

关联Issue #50。

**L1 CPI/PPI与预期差**｜正文：“市场盯的往往不只是数字高不高，而是它比大家预想的高还是低。”屏1选择同比/环比；屏2预期2.8%、实际3.1%，差0.3**个百分点**；屏3切换“高于预期/符合/低于预期”，展示多种可能价格反应；屏4强调经济数据修订、基数效应；测验①差值 A0.3个百分点/B0.3倍/C3%，A；②同比=环比 A是/B否/C必相同，B；③高CPI必使BTC跌 A是/B否/C只短线，B。

**L2 利率与流动性**｜正文：“降息不等于按下币价上涨按钮。”屏1问25bp是多少；屏2政策利率、市场收益率、预期分别展示；屏3模拟市场已提前计价与意外决议两条路径；屏4解释风险偏好也受就业、通胀影响；测验①25bp A0.25个百分点/B2.5个百分点/C25%，A；②降息必涨 A是/B否/C永远，B；③预期会提前反映 A可能/B不可能/C仅公布后，A。

**L3 美元、美债与相关性**｜正文：“两条线看起来反着走，不代表其中一条在控制另一条。”屏1选择观察区间；屏2用固定模拟序列显示正相关/负相关/接近零相关，计算Pearson相关系数并说明不等于因果；屏3切换区间观察数值变化；屏4强调DXY与10年美债收益率口径不同；测验①相关=因果 A是/B否/C只金融市场，B；②收益率涨BTC必跌 A是/B否/C看情境，B；③相关分析要注明 A样本区间/B头像/C钱包，A。

**L4 BTC减半**｜正文：“减半减的是新挖出区块的补贴，不是把大家钱包里的BTC砍掉一半。”屏1猜减半对象；屏2区块补贴序列50→25→12.5→6.25→3.125 BTC；屏3对比单位时间新增发行量与累计存量（区块时间只是近似）；屏4不同历史行情展示“过去不等于保证未来”；测验①减半作用于 A每块补贴/B已有余额/C交易手续费必减半，A；②流通量立即减半 A是/B否/C一周后，B；③历史周期保证未来 A是/B否/C只四年，B。

**L5 宏观事件日历**｜正文：“公布前写好计划，比公布时猜方向靠谱。”屏1给CPI/利率决议模拟日历；屏2填写时区、预期、风险预算、条件A/B与不交易条件；屏3点击揭晓模拟结果，出现“数据高于预期但价格上涨”的反例；屏4总结多因素影响；测验①时区 A要核对/B不用/C只看UTC，A；②数据一个变量足够预测 A是/B否/C总够，B；③计划可以不交易 A可以/B不行/C仅熊市，A。

**验收**：实际数据若引用需注明发布机构、日期、修订；模拟路径不能冒充真实BTC；百分比、百分点、bp、同比环比正确；不得擅自加入当日新闻数据；中文版先审。
