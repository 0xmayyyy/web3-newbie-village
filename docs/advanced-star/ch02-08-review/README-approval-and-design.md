# 第二至第八章统一交付与审批规则（中文优先）

## 绝对顺序
1. GPT提交完整**中文版**教材、术语、公式、示例、逐屏交互、图表数据、题库和答案；用户审核中文稿。
2. 编程布可在独立分支开发**仅中文版预览**，但不得自行改写已给定教学内容；发现疑义提问或单独提修订建议。
3. 用户逐章确认中文版定稿后，**才允许启动该章英文翻译**。目前所有第二至第八章**均未获得英文翻译授权**。禁止提前翻译、批量生成英文正文或将自动机翻混入页面。
4. 中文预览、英文翻译、最终发布是三个独立审批关卡。没有站长明确批准，不得合并到main、部署0xmay.space、修改现有课程或V23核心。

## 每节中文稿交付字段
- 课程目标（学完能做什么、不能推断什么）；术语白话解释；逐屏**可直接显示的中文文案**；精确公式、计算口径与单位；固定模拟数据（JSON/表）；每个按钮/滑块的状态、动作、边界与重置；一正一反场景；3道单选题的A/B/C选项、正确答案、每个错误选项为什么错；互动练习的通过条件；移动端与无障碍方案；实验室衔接；测试向量和验收清单。
- 所有图均由数据驱动生成：OHLC必须满足 low≤min(open,close)≤max(open,close)≤high；副图时间同步；不准AI手绘假K线/指标；每个图有时间轴、数值轴、单位、图例、悬停值；模拟与真实数据严格区分。图形视觉沿用站点紫蓝宇宙风格；Q版黑长卷发、墨镜、白上衣女生只作叙事插画。
- 桌面与360px手机适配；触控目标建议至少44px；可键盘操作；图表提供可读数据表替代；逐根回放不得提前出现未来结果；提交测验前不得泄露答案；每步有重置/返回；语音只朗读已审核中文。

## 研发交付
每课独立Draft PR，提供预览URL、桌面与手机截图、确定性数据、公式单测、操作录屏、回归报告。仅凭Issue创建不代表编程布已接单。遇到需更改既有网站功能时必须停下请求许可。
