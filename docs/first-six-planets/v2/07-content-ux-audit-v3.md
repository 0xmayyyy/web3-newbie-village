# 前六颗星球｜课程体验复核与补充优化建议 V3（待审核）

> 复核依据：仓库 main 的 `js/data.js` 中17个顶层章节及各节标题、已提交六份V2主题稿。**尚未完成实际星球路由和每节正文的逐条比对**，所以以下为可执行核查项与设计建议，不是已经证实的缺陷。不得直接修改线上正文或发布。

## 发现的结构性核查重点
1. **稳定币星球**：17个顶层章节中没有独立命名“稳定币”的章节，基础知识出现在01的“稳定币是什么？”。必须先确认星球路由是否有独立课程源，避免V2误当完整覆盖。
2. **空投星球**：12“Web3玩法地图”包含“空投、积分与测试网”，也含DeFi/NFT/链游/DAO/Meme/RWA/DePIN/AI等，需确认哪些是星球六必修、哪些只做延伸，避免首页入口名为“空投”却让新人被12个玩法同时淹没。
3. **安全内容重叠**：08钱包、09安全、10链上操作、15故障处理、17转账前安全常识有交叉。建议采用“概念首次完整解释→操作课短提醒并链接→故障课给处理步骤”的单一来源策略；不得删去操作页必需的安全提示。
4. **交易所和钱包交叉**：04入金出金、05CEX导航、08钱包、10链上操作应共用同一术语定义，明确“平台账户内划转”和“链上转账”不同；不同地区平台的UID不可假定互通。
5. **入门知识先修**：01→02→03应核对先后，确保在讲FDV、流动性、交易对之前解释币价/供应量/买卖方；技术图不要提前引入太多缩写。
6. **高级课程重复**：03基础滑点、06K线基础、07杠杆风险，与高级星球技术指标、合约课程有内容重合。基础星球只教会辨认和避坑，高级课程再讲计算/模型；保留“想深入学”链接，不做重复长篇。

## 页面阅读节奏细化
- **首屏**：不超过1个核心问题+1段引导（40–70字），避免首屏同时出现巨型标题、插画、定义、三个按钮。
- **定义屏**：先一句白话，再一个例子；专业术语折叠解释，不把术语注释全部常显。
- **图解屏**：桌面可文字与图左右布局；手机改为图在上、文字在下，图内标签≥12px，不能靠缩放把桌面大图塞进360px。
- **误区屏**：统一轻描边“容易弄错”样式，最多2条关键误区；不使用高饱和红色整卡警告造成视觉疲劳。
- **互动屏**：一屏一个主要动作；提交后才显示结果；错误反馈必须说明“错在哪里”和“如何判断”，不只写“再试试”。
- **收尾屏**：一句可记住的结论+下一课按钮；原有测验保留，不重复设置无意义的三连题。
- **文字排版**：中文标点完整，长段按语义拆段；同页最多两级小标题；强调不超过每段1处；行宽/字号/行高沿用V2建议并与现站token比对。
- **低视觉疲劳**：同一页面交替使用纯文字、线性示意图、少量数据卡、可展开补充；禁止每一屏都做成浮空玻璃卡+发光边框；动效可关闭，避免持续漂浮干扰读图。

## 配图的精确验收清单
1. 图中箭头明确表示“信息”“资产”“权限”还是“流程”，不同含义不得用同一种无标签箭头。
2. 每张图有一句图题、一句阅读提示，所有数值、单位、公式和前提可以在展开区复核。
3. 所有交互图有可查看的原始数据表；纯结构图提供文字替代。
4. 模拟钱包/交易所界面显著标注“教学示意”，不要伪装官方实时界面。
5. 同形字符/钓鱼示意域名不可点击，不要求学员输入任何真实私钥、助记词、验证码。
6. 手机360px、390px、桌面1440px截图；深浅背景对比检查；键盘Tab可操作；按钮触控面积≥44px。
7. 金融风险用“可能”“取决于条件”，不使用“必赚、绝对安全、一定追回”等承诺。
