## 1. 已观察到的故障与未证实原因
截图中：价格K线从左到右近乎等斜率单调上涨，几乎无回调/震荡；成交量呈重复的锯齿周期；图例列出EMA20黄线、EMA50蓝色虚线，但主图未见两条线。**这些是可观察事实；原因未核实**。可能涉及指标数据为空、计算预热、图层绘制、Y坐标、裁剪、透明度、线宽、数据生成算法等。禁止未经排查就宣称某个根因。

## 2. 数据生成器：拒绝线性假行情

**首选方案：** 将3–5个经过人工审阅的、版本化、可复现的**仿真BTC OHLCV场景**直接作为静态JSON随代码提供；不用每次刷新随机生成，不用每根固定加价、正弦重复模板或成交量循环数组。每场景至少160根K线，含60根预热与100根可见训练区；展示“模拟BTC/USDT，非真实历史数据”。

必备四场景：
- **A 上升趋势+两次回踩**：至少3段上升推动、2段回调；至少一次靠近EMA20后反弹、一次刺穿EMA20但没有立即破坏较高低点结构；回调的持续根数与幅度不能完全相同。
- **B 下跌趋势+反弹失败**：至少2次较低高点、2次较低低点；价格短暂穿过EMA20后回落；EMA20/50逐渐转向下。
- **C 震荡+假交叉**：至少3次方向转换，EMA20与EMA50至少两次交叉，价格未形成持续单边趋势；用于反驳“交叉必然成功”。
- **D 趋势反转+滞后**：价格先破坏既有高低点结构，EMA20后转向，EMA50更晚；说明均线滞后。**不得人为硬编码“先交叉后价格反转”**。

OHLCV约束：每根 `low<=min(open,close)<=max(open,close)<=high`、volume>0、时间戳严格递增、时间步长一致（除明确标注交易中断）、open与前根close的连续性在仿真24/7行情下合理；影线、实体、涨跌交替必须明显且合理。禁止所有K线同色，禁止超过20根连续同一固定正收益，禁止近乎完全线性的收盘序列，禁止成交量固定周期重复。成交量应与波动和事件部分相关但**不能每次大阳线都机械放量**。场景数据须人工复核，以上检查是最低防线，不是“通过即真实”的保证。

**可重复性：** 场景JSON带`id,version,timeframe,seed/source,expectedFeatures`；若使用随机生成，仅允许在离线构造脚本里使用固定seed，经人工审查后固化结果，运行时不随机重造。每场景提供折线/蜡烛预览供审稿，并附人工标注的推动、回调、震荡、交叉区段。

## 3. EMA计算：必须能用独立样本复核

统一计算约定：默认EMA20与EMA50均使用**收盘价**，`alpha=2/(N+1)`；前N根收盘价的SMA作为首个有效EMA值（索引N-1），其后`EMA[i]=alpha*close[i]+(1-alpha)*EMA[i-1]`；前N-1个值是`null`，**绝不填0、NaN或上一根价格**。EMA50至少需要50根收盘价；提供60根以上预热段，显示区内应均有有效EMA值。切换N必须重新计算。

**可手算单测：** close=[10,11,12,13,14]，EMA3首个有效值在索引2，SMA=(10+11+12)/3=11；alpha=0.5；索引3=12；索引4=13。其他索引为null。测试EMA20/50与独立参考实现对照（浮点容差1e-8），含单调序列、横盘序列、波动序列、参数变化、数据长度不足、非法值。

**诊断日志（开发模式）：** 每次渲染输出场景ID、candles.length、EMA20/EMA50非空数量、首尾有效值、主图可见时间窗、价格轴min/max、两条线样式与visibility；日志不得包含用户隐私。若EMA50有效点数量=0，显示“历史数据不足，无法计算EMA50”，不能留着假图例。

## 4. 绘制规范：K线与EMA同价格轴，线必须看得见

- EMA20：金黄色连续实线、宽2.5px；EMA50：浅蓝色虚线（dash 6px/gap 4px）、宽2.5px；与截图图例完全对应。不可仅有图例无数据曲线。
- 两条线和K线**共用同一时间坐标映射与同一价格Y轴**。不可把EMA误画到成交量副图或采用不同的价格缩放。价格轴范围应包含当前可见K线high/low及可见EMA有效值，留上下边距5–10%。
- `null`不连线；NaN/Infinity不传给绘图API；EMA线段裁剪只限主图区域，不能被成交量图层或背景遮住。绘制顺序建议：网格→K线→EMA→用户交互标记，或者采用清楚的z-index分层；必须实测而非假设。
- “快线/慢线/双线”控制：快线=仅EMA20，慢线=仅EMA50，双线=两条；默认**双线**，显示状态与图例同步；“标出交叉”仅标真实数值交叉，不可把任意交点画上去。
- 主图至少显示价格刻度、十字线与悬浮值：时间、OHLC、EMA20、EMA50；在当前可见K线上选点时对应EMA读数必须与计算结果一致。图例不能仅有“EMA20/EMA50”而曲线不可见。
- 容器宽高/缩放变化时重新计算画布像素比、X/Y映射和clip范围；浏览器DPR=1/2、宽360/390/768/1440都要测。禁止图层被裁剪到画布之外。

## 5. EMA教学交互：修完线之后还必须能教

场景A用户先隐藏均线圈出两次回调→开启EMA20/50观察价格与均线距离→逐根播放并解释“靠近均线不代表反弹已经确认”。场景B识别均线下行和反弹失败。场景C让用户亲自标出假交叉并看到后续K线不延续。场景D让用户先识别价格结构变化，再看EMA20、EMA50依次滞后。

控件必须清晰：默认EMA20/EMA50，修改周期后即时更新数值与线；按钮“显示靠近”必须明示判断标准（例如本课程采用`abs(Close-EMA20)/EMA20<=0.003`），不可暗中把任意蜡烛判为“回踩”。未来K线在练习时隐藏，提示/答案提交前不可见。四场景至少一例“EMA失效/假信号”，不能全是漂亮的成功案例。
