# 技术指标课程极简UI修订 V3：一张仿真K线图 + 少量工具

状态：中文待审核设计文档，尚未改代码、未上线。**本方案取代之前“七个实验室、多排按钮”的界面建议。原有「K线实验室」不属于本次修改范围。**

## 用户反馈及必须修正的问题

截图中的「看懂／自己标记／判断真假／失败案例／新行情考试」「趋势上行与回踩／震荡假交叉／大阴线与滞后」「播放／上一根／下一根／重置」「快线／慢线／双线／标出交叉／显示靠近／答案隐藏中」构成四排控件，过于复杂。教学对象是零基础新人，应该直接看图学习，不需要先学会操作一套交易终端。

**只使用离线仿真BTC OHLCV数据，绝不接入实时行情API。** 仿真价格必须有正常蜡烛实体和影线、上涨、下跌、回调、震荡、穿越均线；成交量不能机械循环。先生成/固化仿真K线，再按收盘价计算指标，不能先手绘均线倒推价格。

```
一张图看懂EMA
EMA跟随价格变化，但不能预测下一根K线。

BTC/USDT · 模拟行情（非实时）
☑ EMA20（快线）黄色实线   ☑ EMA50（慢线）蓝色虚线

┌────────────────────────────────────────┐
│ 一张可交互仿真BTC蜡烛图                 │
│ 有涨跌、回调、横盘、影线                 │
│ 黄EMA20、蓝EMA50叠加在同一价格主图上     │
│ 点击某根K线显示OHLC及对应EMA读数         │
│ 成交量置于图内下方较矮区域               │
└────────────────────────────────────────┘
▶ 播放/暂停  ↺ 重新开始  第30/96根

看这里：K线回调时可能跌穿EMA20，
但这不代表趋势马上反转。

小练习：点出一根跌穿EMA20的K线。[提交]
（可选）再看一个反例
```

**正文第一次出现时必须解释：** 「这里EMA20（快线）和EMA50（慢线）是相对称呼：20周期较短，通常更贴近近期价格；50周期较长，反应相对慢。快线不是预测线，慢线也不是保证支撑。」不能只写“快线”“慢线”让新人猜。

**删除或默认隐藏：**
- 顶部五个教学模式按钮，改成图下自然顺序讲解。
- 第二排三种行情场景按钮，首屏只显示一个精心设计的波动场景；反例用一个轻量文本入口切换。
- 「快线／慢线／双线」三个按钮，改成图例旁两个勾选框，默认双线开启。
- 「标出交叉／显示靠近／答案隐藏中」常驻按钮；在讲解或提交练习时自动标注，减少操作。
- 两个EMA数字输入框：默认20/50；如需修改放在折叠的“更多设置”，默认关闭。
- 「上一根／下一根」大按钮：保留播放/暂停与重置；需要单根操作时使用小图标或键盘，避免拥挤。
- 过长的“模拟、不是实时行情、教学虚构、不是投资建议”胶囊条：标题旁简写「模拟行情·非实时」，完整风险说明放图下。

## 其他指标一律沿用“一张图”的极简原则

- **MACD**：同一容器上方BTC K线、下方MACD副图（DIF、DEA、柱、零轴），同步时间轴；图下短说明与一题找交叉练习。不要再拆成多个模式页。
- **RSI**：上方BTC K线、下方RSI(14)与30/50/70参考线；一题找“RSI超买但价格仍上涨”案例。
- **布林带**：三轨直接叠加BTC K线，点选收口/沿轨/假突破区段显示解释，不另开图。
- **背离**：上方K线、下方MACD或RSI，只保留一个「MACD/RSI」切换；用户在价格和指标各选两点，自动画对应连线；EMA只作趋势辅助，不作为标准背离依据。
- **斐波那契**：同一张仿真K线加「画回撤线」工具；选低高点后叠加0.382、0.5、0.618等水平线，允许拖动/重画；不拆成独立绘图页面。
- **SMC**：一张K线逐根展示结构，少量图层切换「结构／扫荡／FVG／OB」，点击标注显示解释；默认不贴满所有术语，避免信息过载。
- **练习**：每节主图下方一题即时操作练习；可选反例用“再看一个反例”轻量入口；更深入的题库统一放课程末尾，不挤占主页面。

## 技术与验收边界

1. 主图的K线和EMA使用相同时间轴、价格轴；EMA20黄色实线、EMA50蓝色虚线必须清楚穿插在K线中。由仿真OHLCV计算真实数值，不能画假曲线。
2. 至少有上涨、回调、下跌、震荡、假信号；没有机械斜坡和重复量柱。每个场景需有合法OHLCV、固定版本与人工复核。
3. 桌面1440px和手机390px可读；首屏只有一张主图和简短工具，不出现多排模式按钮。
4. 用户点击K线能读出对应指标数值；播放/暂停、重置、图层开关正常；练习中未来K线及答案不提前显示。
5. MACD/RSI副窗与价格主图时间严格对齐；背离的价格两点与指标两点一一对应。
6. **绝不修改原有「K线实验室」的入口、图表、数据、样式、场景或交互。** 如果技术上必须修改共享代码，先列出文件及影响并获得站长单独批准。
7. 提交真实可运行预览、手机和桌面截图、指标计算单测；仅有设计文档不算实现完成。
8. 中文审核通过后才可动生产课程或翻译；未经授权不合并、不部署。
