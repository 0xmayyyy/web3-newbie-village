## 共通教学原则

**目标不是记住金叉、死叉、70/30，而是学会：在BTC K线上找到对应的价格结构→查看指标读数→解释信号形成过程→辨别假信号→说明失效条件。**

三门课各自提供：
- 至少90根完整仿真BTC/USDT OHLCV数据，另有足够指标预热历史；标记“模拟，不是实时行情”。
- **一张主图K线**（价格轴、时间轴、影线、实体、成交量）及需要时的**同步副图**；统一十字光标，点一根K线同步显示价格和指标读数。
- 逐根播放、暂停、单根前进、退回、重置；未来K线和答案默认隐藏。
- “看懂→自己标记→判断真假→看到失败案例→新行情考试”五步，至少三道不同类型练习。
- 所有公式、参数、计算种子、预热期与异常数据规则必须写在代码和界面说明中；不能把“线看起来对”当成正确。
- **不得**把单一指标转成确定性的买卖指令；示例价位与收益均非投资建议。

# 第一课：EMA｜看趋势，不是看一条神奇支撑线

## 1. 学完能做什么
读者能够在陌生K线图中：
1. 找出价格与EMA20、EMA50的相对位置；
2. 判断均线是否上行、下行或趋平；
3. 识别价格回踩EMA后**是否真的出现价格反应**；
4. 区分均线交叉、假交叉与震荡区的频繁交叉；
5. 解释为什么EMA有滞后、不能当作必然支撑/阻力。

## 2. 正文（新手版）
**EMA就像一条“更重视最近价格”的平均轨迹。** 你看到BTC最近连续上涨，EMA通常会慢慢抬头；BTC突然跌一根大阴线，EMA不会像价格那样瞬间跳下去，因为它还包含之前的价格。

常见的EMA20、EMA50，只是计算所使用的K线根数不同。**20根不等于20天**：如果你看1小时图，EMA20代表20根小时K线的指数加权均值；看日线图才对应20根日K线。

EMA20通常比EMA50对新价格更敏感。价格位于两条EMA之上、两条线都向上，可能提示当前偏强；但**“偏强”不是下一根一定涨**。价格下穿EMA，也可能只是短暂回调。

有些人说“回踩EMA20就是买点”。别直接照做。先问：它原本是上涨趋势吗？回踩后有没有出现明确的价格反应？是否出现连续跌破？附近有没有前低、成交量和其他结构证据？**EMA是观察工具，不是自动订单。**

## 3. 画面与互动
**主图始终同时显示真实可计算的仿真BTC蜡烛图、EMA20（实线）和EMA50（虚线）**，可切换任一线。十字光标显示：时间、OHLC、EMA20、EMA50、EMA20相较前一根的变化。

三个剧情：
- **趋势上行与回踩**：逐根播放；用户先点出均线持续抬升区，再点“回踩EMA20附近”的K线；系统解释“接近均线”与“确认反弹”不是同一事件。
- **震荡假金叉**：价格横盘、EMA20和EMA50反复交叉；用户圈出至少两次交叉，发现单凭交叉容易被来回打脸。
- **价格强跌、EMA滞后**：一根快速下跌K线先穿过均线，EMA仍在缓慢变化；用户解释为何均线不能预测突发波动。

**交互控件：** EMA周期20/50默认，允许5–200调整；“仅EMA20／仅EMA50／双线”“标出交叉”“显示价格反应”“隐藏答案”。“回踩”必须定义为K线Low或实体触及某个可设置的距离带，例如`abs(Close-EMA20)/EMA20<=0.3%`，**此阈值是教学规则，不是行业通用信号**；如果使用Low/High触碰则采用不同明确规则，不能混用。

**EMA计算**：`alpha=2/(N+1)`；`EMA_t=alpha*C_t+(1-alpha)*EMA_(t-1)`。首N根收盘价SMA作为种子，之后递推；预热不足显示“数据不足”，而非画0。用户切换周期后重算所有值。

## 4. 三道练习
- **识别题**：在上行场景中，点出两条EMA同时上行且价格大部分时间位于其上的区段；解释为什么只是趋势观察。
- **反例题**：EMA20上穿EMA50，但价格处于窄幅震荡，是否能直接判定后续上涨？正确：不能，交叉可能频繁反复。
- **操作题**：给新行情，隐藏两条线，先判断趋势，再开启EMA核对；指出一处EMA失效或滞后例子。

**测验**：BTC在1小时图的EMA20意味着什么？A 过去20天的简单平均；B 对20根小时K线收盘价进行指数加权的均线；C BTC未来20小时预测价格。**答案B**。A混淆周期与算法；C把历史平滑误认为预测。

**验收：** EMA20/50数值、线条和价格同轴；切周期正确重算；震荡反例必须出现；不得标“金叉=必涨”。

# 第二课：MACD｜看动量怎样变化，不只背金叉死叉

## 1. 学完能做什么
读者能够指出MACD副图中DIF、DEA（信号线）、柱状图和零轴，理解它们各自的含义；辨认零轴上下的交叉、柱体缩短/扩大、顶底背离，并知道为什么**“绿柱变短”不等于价格已经上涨**。

## 2. 正文（新手版）
**MACD可以把两条不同速度的EMA之间的差异画出来。** 想象两个人跑步：一个反应快，一个反应慢。快的和慢的距离拉大，说明近期走势与较慢趋势的差异在扩大；距离缩小，说明这种差异在收敛。但这不是价格上涨或下跌的保证。

本课程默认MACD(12,26,9)：
- **DIF线**：EMA12减EMA26。DIF在零轴上方，说明快EMA高于慢EMA；在下方则相反。
- **DEA/信号线**：DIF的9周期EMA，用于平滑DIF。
- **柱状图**：DIF减DEA，正负和长度反映两条线之间的差异。部分平台柱值显示为两倍，本课程明确使用**1倍差值**。

**金叉**是DIF由下向上穿过DEA；**死叉**相反。但必须先看它们在零轴上方还是下方、K线是否有相应的价格结构。金叉在下跌趋势中也可能只对应短暂反弹；死叉在上涨趋势中也可能只是回调。

**柱体缩短的真正含义**：例如柱从-150变成-60，代表DIF相对DEA的负差值收窄，不等于BTC已经涨了，也不等于价格必然反转。必须同步看上面的K线。

**背离**：在价格主图选两个已确认高点，如果价格第二高点更高，而对应MACD DIF第二个高点更低，可以称为本课程的常规顶背离；底背离反向。若选择柱状图来比较，就必须**全程比较柱状图的局部极值**，不能拿DIF第一个峰和柱体第二个峰拼接。背离不保证反转。

## 3. 画面与互动
主图为仿真BTC K线+可选EMA12/26；下方独立MACD副图必须同时画**DIF实线、DEA虚线、正负柱、0轴**。两个窗口共享X轴与十字光标。选任一K线，上下同时高亮，显示收盘价、EMA12、EMA26、DIF、DEA、柱值；允许隐藏某一条线进行认知练习。

四个剧情：
1. **零轴上方金叉**：先看K线是否形成较高低点，再看DIF上穿DEA；用户标出交叉的准确K线，并判断“趋势延续候选，而非买入保证”。
2. **零轴下方金叉却继续下跌**：显示短暂反弹后新低；用户必须说出“交叉与大趋势矛盾”。
3. **负柱缩短但价格继续下跌**：主图继续创低，副图负柱绝对值减小；用户点出“下跌动量变化”与“价格已转涨”的区别。
4. **价格新高、DIF峰值未创新高**：上下两窗画A/B与A′/B′连线，时间严格对齐；另给一个“极值不匹配”的假背离反例。

**交互操作：** 切换“找金叉/死叉”“找零轴变化”“柱体变化”“手画背离”；背离模式要求在价格窗选两个摆动点，再在MACD窗选相应DIF峰谷；支持切换“用柱状图比较”，切换后清空旧指标点。每一步即时反馈“时间窗口不对应”“第二价格高点没有更高”“DIF没有更低高点”等具体错误。

**计算：** `DIF=EMA(Close,12)-EMA(Close,26)`；`DEA=EMA(DIF,9)`；`Histogram=DIF-DEA`。EMA种子采用上述固定规则，DEA仅在有效DIF序列上初始化；不足时显示不可计算，不能前向填0。交叉判定使用前一根与当前根的相对差值符号变化，并定义相等时的处理（建议忽略连续相等直到出现严格穿越）。

## 4. 三道练习
- **认知题**：点击副图中的DIF、DEA、柱、0轴并解释各自作用。
- **辨伪题**：MACD负柱缩短但K线仍创低，是否说明价格已经反转？正确：不能。
- **图上操作题**：在隐藏提示的新BTC行情中标记金叉位置、零轴区域和一次符合/不符合定义的背离，并说明失效情境。

**测验**：MACD柱从-120变为-40，但BTC收盘价仍下跌，最准确的说法是？A BTC已经确认上涨；B 价格一定会在下一根反弹；C DIF与DEA的负差值在收窄，不能单独证明价格反转。**答案C**。A/B把动量变化误当未来价格确定性。

**验收：** K线与副图X轴严格同步；DIF/DEA/柱数值与定义一致；正负柱清楚；零轴明显；交叉位置准确；至少一个金叉失败和一个背离失败反例；无未来数据泄漏。

# 第三课：RSI｜超买不是马上跌，超卖不是马上涨

## 1. 学完能做什么
读者能识别RSI(14)副图、30/50/70参考线；知道强趋势中RSI可能长期高于70或低于30；在价格与RSI中画出常规顶/底背离；区分“指标相对强弱变化”和“价格一定转向”。

## 2. 正文（新手版）
**RSI看的是最近一段时间上涨和下跌变化的相对强度，不是BTC贵不贵的估值表。**

它通常显示在0到100之间。很多图表用70和30作参考：
- **高于70**常被称为超买区，但不代表价格“已经太贵、马上必须跌”。强上涨趋势里，RSI可能在高位停留很久。
- **低于30**常被称为超卖区，但不代表价格“已经够便宜、马上必须涨”。强下跌趋势里，RSI可能持续低位。
- **50附近**可辅助观察相对上涨与下跌强度，但不是神奇分界线。

想象BTC连续上涨十几根K线，RSI升到78。有人看到“超买”立刻做空，结果价格继续涨。为什么？**RSI说的是最近上涨很强，不是告诉你下一根必跌。**

RSI背离要把**价格的两个已确认高点/低点**与**相应时间窗口的RSI两个峰/谷**一一对照：
- 顶背离：价格更高高点，RSI更低高点；
- 底背离：价格更低低点，RSI更高低点。
“RSI从78降到70”本身**不是**背离，必须有对应的价格结构。

## 3. 画面与互动
主图仿真BTC K线；下方RSI副图显示RSI(14)实线与30/50/70三条清晰标注的参考线。两个图严格共享时间轴；十字光标显示当前收盘价、RSI值、与上一根变化。

四个剧情：
1. **强上涨持续超买**：RSI连续多根>70，K线继续创高；让用户选择“RSI高位=强势表现”还是“必然立刻做空”，揭示误区。
2. **强下跌持续超卖**：RSI多根<30，K线继续创低；反驳“低于30必抄底”。
3. **价格新高但RSI高点下降**：价格图和RSI副图A/B点连线，用户亲自画顶背离；同理准备底背离场景。
4. **假背离**：RSI下降，但价格第二高点未高于第一高点，或者两个指标点时间不匹配；系统解释为什么不符合本课程定义。

**交互：** 用户先用光标找价格两处摆动点，再选RSI对应局部峰谷；“显示对应时间垂线”帮助核对，提交前不显示标准线；切换“RSI>70持续天数”“RSI<30持续天数”“背离判断”“只看K线先猜强弱”四种模式。允许参数5–30，默认14；30/70阈值可调但必须标注只是参考阈值。

**计算**：RSI使用Wilder方法，初始14个涨跌变化的简单平均作为AvgGain、AvgLoss，再递推`AvgGain_t=(13*AvgGain_(t-1)+Gain_t)/14`、Loss同理；`RSI=100-100/(1+AvgGain/AvgLoss)`。当AvgLoss=0且AvgGain>0，RSI=100；当AvgGain=0且AvgLoss>0，RSI=0；两者都为0时**本课程约定RSI=50**，注明不同平台可能处理不同。预热不足时显示不可计算。变更周期时按相同方法重算。

## 4. 三道练习
- **识别题**：在图中找出RSI高于70但BTC仍上涨的连续区段。
- **反例题**：RSI跌到25后BTC继续下跌，解释为什么“超卖=必反弹”不成立。
- **画线题**：在未知BTC行情中标出两个价格高点与RSI高点，判断是否顶背离；另选底背离案例，解释何时不成立。

**测验**：BTC RSI(14)=78，最准确的说法是？A 最近上涨相对强，可能持续高位，但不能单凭78判断马上下跌；B 一定要立刻做空；C BTC已经确定到顶。**答案A**。B/C把参考阈值误当预测。

**验收：** RSI数值范围0–100，30/50/70标签可读；参数和计算边界一致；必须有持续超买、持续超卖、真/假背离及失败案例；不输出“超买必跌/超卖必涨”。

# 第四部分：三指标联合训练（不能代替三门独立课）

**综合场景：** 仿真BTC处于上涨趋势，EMA20/50上行；MACD正柱缩短；RSI从78回落到69；K线仍未跌破最近已确认的关键摆动低点。

用户必须分四栏作答：
1. **K线事实**：当前仍为上涨结构还是已经跌破关键结构？指出哪根K线和哪个价格。
2. **EMA观察**：两条均线方向、价格位置如何？有没有发生回踩？
3. **MACD/RSI观察**：动量减弱是否意味着价格已经反转？是否满足背离所需的两个对应极值？
4. **结论与失效**：能说“动量可能减弱，但仅凭这些不能确认反转”；给出需要进一步观察的价格结构和一个失败可能性。**允许并鼓励“不足以判断，不行动”**。

**独立考试数据**不得重复教学场景；不得只看用户选择“看涨/看跌”给分。建议评分：价格结构定位40%、指标解释30%、假信号/失效识别20%、风险与不确定性10%。
